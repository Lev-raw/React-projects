# Currency Exchanger

A responsive currency conversion app built with React and Vite. Select two currencies, enter an amount, and get the latest exchange rate from the currency API.

![Currency Exchanger preview](./public/currency-exchanger-preview.png)

## Features

- Convert between a wide range of currencies using current exchange rates.
- Swap the source and target currencies with one click.
- Responsive interface with a video background.
- Accessible form controls with labelled inputs.

## Tech stack

- React
- Vite
- Tailwind CSS
- Currency API

## Getting started

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
